# Design 1 — Système de design + mode sombre — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Poser les fondations visuelles : accent **corail**, neutres chauds, police **Geist** réellement appliquée, et un **mode sombre** fonctionnel (suivi du système + bascule mémorisée) — sans toucher à la logique métier.

**Architecture:** Tailwind v4 utilise déjà des **jetons en variables CSS** (oklch) dans `app/globals.css` avec un bloc `:root` (clair) et `.dark` (sombre), et le variant `dark` est câblé. On ajuste les jetons (corail + neutres chauds + police), puis on ajoute **`next-themes`** (provider + bascule). Aucune logique métier, Server Action ni test existant n'est modifié.

**Tech Stack:** Next.js 16 (App Router), Tailwind v4, shadcn/ui, `next-themes`, `lucide-react` (déjà installé), `next/font` (Geist, déjà chargé).

## Global Constraints

- Périmètre **présentation uniquement** : aucune logique métier, Server Action, sécurité ou calcul modifié.
- Accent **corail** (`oklch(0.64 0.19 33)` clair / `oklch(0.69 0.19 33)` sombre) réservé aux actions principales (`--primary`) et au focus (`--ring`).
- Neutres **chauds** ; statuts inchangés (le rouge `--destructive` reste).
- Mode sombre via **variables CSS** + `next-themes` : suit le système par défaut, bascule clair/sombre, choix mémorisé, pas de flash.
- Build vert, lint propre, **tests existants au vert** (ils ne dépendent pas du style).
- Git : branche `feat/design-systeme` (déjà active), commits petits, jamais de push direct sur `main`.
- Décision d'architecture notable → ADR dans `docs/historique/adr/`.
- Environnement : Windows, shell PowerShell.

### Task 2 : Mode sombre (next-themes + provider + bascule)

**Files:**

- Create: `components/theme-provider.tsx`, `components/theme-toggle.tsx`
- Modify: `app/layout.tsx` (provider + `suppressHydrationWarning`)
- Modify: `app/page.tsx` (placer la bascule temporairement pour tester — sera déplacée dans la coquille de navigation en sous-phase 2)

**Interfaces:**

- Consumes: `next-themes`, `lucide-react`.
- Produces:
  - `ThemeProvider` (composant client enveloppant `next-themes`).
  - `ThemeToggle` (bouton client qui bascule clair/sombre).

- [ ] **Step 1: Installer next-themes**

Run :

```bash
npm install next-themes
```

- [ ] **Step 2: Créer le ThemeProvider**

Créer `components/theme-provider.tsx` :

```tsx
"use client";

import { ThemeProvider as NextThemesProvider } from "next-themes";
import type { ComponentProps } from "react";

export function ThemeProvider({ children, ...props }: ComponentProps<typeof NextThemesProvider>) {
  return <NextThemesProvider {...props}>{children}</NextThemesProvider>;
}
```

- [ ] **Step 3: Brancher le provider dans le layout**

Dans `app/layout.tsx` :

1. Ajouter l'import :

```tsx
import { ThemeProvider } from "@/components/theme-provider";
```

2. Ajouter `suppressHydrationWarning` à la balise `<html>` (à côté de `lang="fr"` et `className=...`).
3. Envelopper `{children}` dans le `<body>` :

```tsx
<body className="flex min-h-full flex-col">
  <ThemeProvider attribute="class" defaultTheme="system" enableSystem disableTransitionOnChange>
    {children}
  </ThemeProvider>
</body>
```

- [ ] **Step 4: Créer la bascule de thème**

Créer `components/theme-toggle.tsx` :

```tsx
"use client";

import { useTheme } from "next-themes";
import { Moon, Sun } from "lucide-react";
import { Button } from "@/components/ui/button";

export function ThemeToggle() {
  const { resolvedTheme, setTheme } = useTheme();
  const estSombre = resolvedTheme === "dark";

  return (
    <Button
      type="button"
      variant="outline"
      size="icon"
      aria-label={estSombre ? "Passer en clair" : "Passer en sombre"}
      onClick={() => setTheme(estSombre ? "light" : "dark")}
    >
      {estSombre ? <Sun className="size-4" /> : <Moon className="size-4" />}
    </Button>
  );
}
```

- [ ] **Step 5: Placer la bascule temporairement sur l'accueil (pour tester)**

Dans `app/page.tsx` :

1. Ajouter l'import :

```tsx

```

2. Ajouter `<ThemeToggle />` juste après le titre `<h1>…CRM-BB…</h1>` (placement provisoire ; la sous-phase 2 la déplacera dans la barre de navigation).

- [ ] **Step 1: Écrire l'ADR**

Créer `docs/historique/adr/0010-theme-design-tokens-darkmode.md` :

```markdown
# ADR 0010 — Thème par jetons CSS + mode sombre (next-themes)

**Date :** 2026-06-20
**Statut :** Accepté

## Contexte

La refonte du design veut une identité corail/pro et un mode sombre, sans dupliquer les
styles ni alourdir le bundle.

## Décision

On s'appuie sur les **jetons CSS** déjà en place (Tailwind v4, oklch) avec deux jeux de
valeurs (`:root` clair / `.dark` sombre). L'accent `--primary`/`--ring` passe en corail.
La bascule de thème utilise **`next-themes`** (classe `dark` sur `<html>`, suivi du système,
choix mémorisé, `suppressHydrationWarning` pour éviter le flash).

## Alternatives écartées

- Thème géré à la main (contexte React + localStorage) : réinvente `next-themes`.
- Deux feuilles de style séparées : duplication et risque d'incohérence.

## Conséquences

- Bascule clair/sombre gratuite pour tous les composants qui consomment les jetons.
- Toute nouvelle couleur doit passer par un jeton (clair + sombre) pour rester cohérente.
```
